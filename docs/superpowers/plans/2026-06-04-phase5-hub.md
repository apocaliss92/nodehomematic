# nodehomematic — Fase 5: Hub (sysvar, programmi) + stanze/funzioni via ReGa

> **For agentic workers:** TDD module-by-module. Builds on Phases 1–4 (merged, 0.2.0). Adds the hub layer (system variables + programs) to the facade, and fixes the Phase-2 rooms/functions gap with a custom ReGa script keyed by channel address.

**Goal:** Esporre sulla facade `Homematic`: system variables (lista, lettura, scrittura) e programmi (lista, esecuzione, attiva/disattiva). Inoltre popolare `rooms`/`functions` dei device tramite uno **script ReGa custom** (channel-address-keyed), risolvendo il gap della Fase 2.

**Architecture:** Un `ReGaRunner` esegue script ReGa via JSON-RPC `ReGa.runScript` (param `script` = corpo, sostituzione `##key##`, risultato = stringa JSON da ri-parsare + sanitize control-chars; nomi UriEncoded → decode latin1). Un `HubFetcher` usa JSON-RPC (`SysVar.*`, `Program.*`) + ReGa per sysvar/programmi/descrizioni. Le stanze/funzioni vengono lette da uno script ReGa custom e merge-ate nei `DeviceNode`. La facade espone snapshot immutabili + comandi.

**Tech Stack:** TypeScript strict. Test: vitest + FakeCcu (estendere il JSON-RPC: SysVar.*, Program.*, ReGa.runScript) + e2e reale (i sysvar/programmi/stanze reali).

## Facts (da aiohomematic — autorevoli)

### ReGa.runScript
- Metodo JSON-RPC `ReGa.runScript`, param key **`script`** = corpo intero. Sostituzione placeholder `##key##` → valore (escape ReGa: `\`→`\\`, `"`→`\"`). Risultato in `result` è una **stringa JSON** → sanitize control-chars non escapati → `JSON.parse`. Nomi/descrizioni `UriEncode`d → `decodeURIComponent` in **latin1/ISO-8859-1**.

### System variables
- `SysVar.getAll` → entry `{ id, name, type, value, unit, isInternal, valueList ("a;b;c"), minValue?, maxValue? }`. Niente description (separata).
- `HubValueType`: ALARM, FLOAT, INTEGER, LIST, LOGIC, NUMBER, STRING. Normalizza NUMBER→FLOAT se il valore contiene `.`, altrimenti INTEGER.
- Parse valore: ALARM/LOGIC→bool (`to_bool`: y/yes/t/true/on/1); FLOAT→number; INTEGER/LIST→int; STRING/NUMBER→passthrough.
- Read singolo: `SysVar.getValueByName {name}`.
- Write (dispatch sul tipo del VALORE JS): bool→`SysVar.setBool {name, value:0|1}`; string→**ReGa** `set_system_variable.fn`; numerico→`SysVar.setFloat {name, value}`.
- Descrizioni: ReGa `get_system_variable_descriptions.fn` → `[{id, description}]`. Il marker **`HAHM`** nella description = `extended_sysvar` = sysvar SCRIVIBILE; senza marker = read-only sensor.

### Programmi
- `Program.getAll` → `{ id, name, isActive, isInternal, lastExecuteTime }`.
- `Program.execute {id}`. Attiva/disattiva: ReGa `set_program_state.fn` `{id, state:"1"|"0"}`.

### Stanze/funzioni (Opzione B — script ReGa custom, channel-address-keyed)
- Primitive ReGa (da `get_service_messages.fn`): `object oChn = dom.GetObject(iChnId); oChn.Address()` → "ABC123:1"; `foreach(sRoomId, oChn.ChnRoom()) { dom.GetObject(sRoomId).Name() }`; `foreach(sFuncId, oChn.ChnFunction()) { ... }`.
- Scrivere uno script che enumera i canali ed emette JSON `{ "<channelAddress>": ["RoomName", ...] }` per rooms e idem per functions (UriEncode i nomi). Invocare via `ReGa.runScript`.
